# NuliBlog

适用于 Z-BlogPHP 的阅读型博客主题。主题目录、ID、函数、配置项、字体别名及浏览器状态均采用 NuliBlog 命名。

## 安装或切换

1. 将整个 `NuliBlog` 文件夹上传到 `zb_users/theme/NuliBlog/`。
2. 在后台“主题管理”中启用 NuliBlog，不要直接修改系统的主题配置记录。
3. 首次启用会按字段组合识别现有主题设置，将唯一匹配项导入新配置；已存在的新设置不会被覆盖，原配置记录保留用于核对。若存在多个匹配配置，不自动选择。
4. 检查主题设置、LOGO、字体、文章目录及菜单状态，然后在后台更新缓存并强制刷新。
5. 确认切换成功后，可从服务器删除不再使用的旧主题目录。

菜单和目录的兼容浏览器状态会迁移到新命名空间；文章页与列表页仍分别记忆。

## 功能

- MiSans 分包字体、蓝色主题、响应式导航及工具栏。
- 首页置顶与列表摘要、简洁表格、紧凑评论区。
- H2/H3 文章目录、章节高亮、显示开关和独立的菜单/目录记忆。

第三方组件及字体附带的许可信息按其原文件保留。
